## 🤝 如何贡献

1. **Fork** 本仓库并创建新分支
2. 在对应的分类下补充条目，格式如下：

   ```markdown
   | [项目名称](链接) | 一句话简介 |
   ```

3. 提交 **PR**，或直接提 **Issue** 推荐你喜欢的项目 🎉
