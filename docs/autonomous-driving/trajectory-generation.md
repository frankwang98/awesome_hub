# 📈 轨迹生成与优化

> 规划的关键一步，是把「一条几何路径（Path）」升级为「一条带时间、速度、加速度的运动轨迹（Trajectory）」。这一步既要**平滑**（曲率连续、符合运动学），又要**可行**（速度/加速度受限、能避障），是规划算法中技术含量很高的部分。

## 1. Path vs Trajectory

| | Path（路径） | Trajectory（轨迹） |
| --- | --- | --- |
| 内容 | 空间上的点序列 | 时空上的运动描述 |
| 维度 | `(x, y)` | `(x, y, θ, v, a, t)` |
| 表达 | 只有几何线 | 有速度、加速度、时间戳 |
| 用途 | 宏观参考 | 供控制器实际执行 |

示例轨迹：
```
t=0s   x=0   y=0   v=0     a=0
t=1s   x=3   y=1   v=3     a=3
t=2s   x=8   y=4   v=5     a=2
...
```

## 2. 曲线表达与插值

轨迹的几何基础是一系列平滑曲线：

| 曲线 | 特点 | 典型用途 |
| --- | --- | --- |
| **直线 / 圆弧** | 简单，但直线与圆弧交界处曲率不连续 | 简单运动、转弯示意 |
| **Bezier（贝塞尔）** | 通过控制点平滑连接，易实现 | 路径平滑、简单换道 |
| **B-Spline** | 分段、局部可控、可做到 C1/C2 连续 | 轨迹平滑、连续曲率 |
| **Clothoid（回旋线）** | 曲率随弧长**线性变化**，曲率连续无跳变 | 高速道路、车道曲率建模 |

> 曲率 `κ = 1/R`（R 为转弯半径）。高速驾驶对**曲率连续性**要求高，避免方向盘/加速度突变。

## 3. 多项式轨迹（Polynomial Trajectory）

用多项式函数表示位置随时间的变化，是轨迹生成最常用的方法。

### 五次多项式（Quintic Polynomial）
```
x(t) = a0 + a1·t + a2·t² + a3·t³ + a4·t⁴ + a5·t⁵
```
- 有 6 个未知系数，可由**位置、速度、加速度**各两组边界条件（起点/终点）唯一确定。
- 保证**位置、速度、加速度均连续**，轨迹平滑。
- **应用**：换道、起步停车等横向/纵向轨迹。

### 更高阶与样条
- **七次多项式**：可进一步约束加加速度（jerk），使乘员更舒适。
- **样条拼接**：分段多项式拼接成整段轨迹，兼顾复杂路形与连续性。

## 4. 轨迹优化（Trajectory Optimization）

当轨迹需要同时满足「平滑、避障、效率」等多目标时，用**优化**的方法求解。

### 目标函数（代价函数）
优化过程最小化加权代价，例如：
```
J = w1·(与参考线的偏差) + w2·(曲率/加速度/jerk 的平方和)
  + w3·(到障碍物的安全距离惩罚) + w4·(到达时间/行驶距离)
```

### 常见方法
- **数值优化 / 二次规划（QP）**：把轨迹点作为变量，构造代价与约束，用优化器求解。
- **图优化**：在 Frenet（s,l）坐标系下把轨迹建模为图，迭代优化（如 Lattice Planner 中的优化）。
- **MPC（模型预测控制）**：既可用于规划轨迹，也可用于跟踪控制，见 [控制](control.md)。
- **TEB（Timed Elastic Band）**：把轨迹看成一条「带时间刻度的弹性带」，通过优化使时间、曲率、避障综合最优，AGV/移动机器人常用。

## 5. Frenet 坐标系下的轨迹规划

在结构化道路上，广泛使用 **Frenet 坐标系**（沿参考线的 s 纵向 + 垂直偏移 d 横向）：

- **纵向规划（s-t）**：决定速度曲线，处理限速、跟车、停止线。
- **横向规划（s-d）**：决定左右偏移，处理变道、避障。
- **Lattice Planner（格点规划）**：在 s-d-t 空间采样一系列候选轨迹，用代价函数选出最优，是自动驾驶常用的轨迹生成框架。

## 6. 通用流程小结

```
① 确定参考线(参考路径/车道中心) → ② 转换到 Frenet 坐标
→ ③ 生成候选轨迹集合(采样/多项式/优化) → ④ 代价评价(平滑+安全+效率)
→ ⑤ 运动学/动力学可行性校验 → ⑥ 输出最优 Trajectory
```
