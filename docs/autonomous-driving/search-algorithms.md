# 🔍 搜索算法（搜路）

> 搜索（Search）是路径规划的地基——在离散的图或连续空间里寻找一条可行且尽量最优的路径。从经典的图搜索到为车辆运动学定制的 Hybrid A*，再到随机采样类算法，构成了一套完整的「搜路」武器库。

## 1. 图搜索基础

把环境建模成**图**（节点 + 边 + 边代价），路径规划就变成「图上找最优路径」。

### BFS（广度优先搜索）
- 逐层向外扩展，**保证找到最短路径**（在无权图上）。
- 缺点：没有方向性、收敛慢，不适合大图。

### Dijkstra（迪杰斯特拉）
- 带权边的最短路径算法，`代价 = 已走过的成本 g(n)`。
- 一定找到**全局最短路径**，但会向四周均匀扩展，效率较低。

### A*（A Star）—— 最重要的图搜索
- 在 Dijkstra 基础上加入**启发式估计**，公式：
  ```
  f(n) = g(n) + h(n)
  ```
  - `g(n)`：从起点到节点 n 的实际代价
  - `h(n)`：从节点 n 到目标的估计代价（启发函数）
  - `f(n)`：节点 n 的总估计代价，优先扩展 f 最小的节点
- 当 `h(n)` 满足**可采纳性**（不高估到目标的代价）时，A* 既能保证最优，又比 Dijkstra 高效得多。
- **应用**：栅格地图（Occupancy Grid）、Costmap 上的全局路径搜索，是 ROS Nav2 中全局规划器的核心。

## 2. Hybrid A*（混合 A*）

> 普通 A* 只考虑 `(x, y)`，但汽车有航向 `θ`，且**不能横着走**（受最小转弯半径约束）。

- **状态空间**：`(x, y, θ)`，把连续的运动学约束纳入搜索。
- **做法**：在栅格上按车辆运动学「模拟前进」（如向前/向后打不同方向盘角度），搜索出**真正可行驶**的路径。
- **优势**：找到的路径天然满足车辆转弯约束，无需后期大改。
- **应用**：自动泊车、复杂场景下的路径搜索，是自动驾驶中最实用的搜索类算法之一。

## 3. RRT 及其变种（随机采样）

- **RRT（Rapidly-exploring Random Tree）**：随机采样空间，把节点连成树，逐渐探索到目标。
  - 优势：适合高维、复杂环境，探索能力强。
  - 缺点：路径不平滑、不是最优、结果随机。
- **RRT***：在 RRT 基础上增加「重连」优化，**渐近最优**。
- **Informed RRT***：用椭圆采样区域约束搜索范围，收敛更快。
- **应用**：机械臂运动规划、自动驾驶绕障、非结构化场景路径搜索。

## 4. 动态环境搜索

| 算法 | 特点 | 适用 |
| --- | --- | --- |
| **D\* / D\* Lite** | 支持局部地图变化后**增量式**重新规划，不必全图重算 | 动态障碍物环境 |
| **DWA / TEB**（局部） | 不属于图搜索，是速度空间/轨迹束搜索，见 [规划总览](planning.md) | 局部实时避障 |

## 5. 算法对比

| 算法 | 状态空间 | 是否考虑车辆运动学 | 最优性 | 适用场景 |
| --- | --- | --- | --- | --- |
| BFS | 离散格点 | 否 | 最短（无权） | 教学/简单图 |
| Dijkstra | 离散格点 | 否 | 全局最优 | 通用图搜索 |
| A* | 离散格点 | 否 | 最优（h 可采纳时） | 栅格地图全局规划 |
| Hybrid A* | (x,y,θ) 连续 | **是** | 次优 | 泊车/结构化搜索 |
| RRT | 连续 | 可选 | 非最优 | 复杂/高维环境 |
| RRT* | 连续 | 可选 | 渐近最优 | 高维最优搜索 |

## 6. 选择建议

- **结构化道路全局搜索**：A*（配 Costmap）。
- **泊车/窄路搜索**：Hybrid A*（自带运动学约束）。
- **复杂/非结构化绕障**：RRT* / Informed RRT*。
- **动态环境快速重规划**：D* Lite 类增量算法。
