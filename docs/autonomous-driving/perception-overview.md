# 👁️ 感知流程概览（大体流程）

> 感知（Perception）是自动驾驶的「眼睛」——负责把传感器数据转换成车辆能理解的**环境信息**。本文只给出一套**通用的大体流程**，帮你建立对感知模块的整体认知，不过度深入各细分算法细节。

## 1. 感知要回答的问题

感知模块最终要输出这些「世界状态」：

| 问题 | 输出 |
| --- | --- |
| 路上有什么？ | 障碍物（车/人/物） |
| 车在哪条车道？ | 车道线、可行驶区域 |
| 信号灯/标志说了什么？ | 交通标识语义 |
| 我周围环境长什么样？ | 局部地图 / 语义地图 |

## 2. 感知大体流程

```
┌────────┐  ┌────────┐  ┌────────┐
│ 数据输入 │→│ 数据预处理│→│ 环境感知 │→ 融合 → 输出
└────────┘  └────────┘  └────────┘
  相机       标定       目标检测
  LiDAR      时间同步    车道线/可行驶区域
  Radar      去噪       交通标识识别
  IMU/GNSS             …
```

### ① 数据输入
- **相机**：RGB 图像，信息丰富。
- **激光雷达（LiDAR）**：点云，测距精准。
- **毫米波雷达（Radar）**：测速测距，全天候。

### ② 数据预处理
- **传感器标定**：内参 + 外参，把不同传感器对齐到同一坐标系。
- **时间同步**：多传感器时间戳对齐。
- **去噪/滤波**：去除点云噪点、图像模糊等。

### ③ 环境感知（核心）
- **目标检测与识别**：检测车、人、障碍物，并分类。
- **车道线与可行驶区域**：识别车道结构，判断哪里能走。
- **交通标识识别**：识别红绿灯、限速牌、标志。
- **BEV（鸟瞰图）感知**：把多传感器信息统一到车辆俯视视角，是现代感知的主流范式。

### ④ 多传感器融合
- 把相机、LiDAR、Radar 的结果**融合**，取长补短（如相机认颜色、LiDAR 测距离）。
- 融合可在**数据层**（原始数据融合）或**结果层**（检测结果融合）进行。

### ⑤ 输出
- 目标列表（位置、速度、类别、朝向）
- 车道线 / 可行驶区域 / 语义地图
- 供下游的**预测、决策、规划**使用

## 3. 感知与预测/规划的衔接

感知输出并不直接给规划，中间通常还有：

```
感知(检测目标) → 预测(目标未来轨迹) → 决策/规划(避让/跟车)
```

- **预测（Prediction）**：根据目标历史状态，预测它未来几秒的可能轨迹（这是另一个细分方向）。
- 规划层基于「感知到的当前世界 + 预测的未来世界」来做决策。

## 4. 感知的工程挑战

- **实时性**：感知要在几十毫秒内输出，且持续运行。
- **鲁棒性**：雨天、黑夜、强光、遮挡等恶劣条件下仍要可靠。
- **算力**：深度学习模型推理需要 GPU/NPU 加速。
- **数据闭环**：感知模型依赖大量标注数据与持续迭代。
