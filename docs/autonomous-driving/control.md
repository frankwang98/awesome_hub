# 🎛️ 控制（跟踪生成路径/轨迹）

> 规划生成了轨迹，但要让车真正沿着轨迹走，还需要**控制**模块。控制根据车辆当前状态与目标轨迹的偏差，计算出油门、刹车、方向盘转角等控制量，并**闭环纠偏**。这是从「纸上轨迹」到「车轮动作」的关键一环。

## 1. 车辆运动模型（控制的地基）

### Bicycle Model（自行车模型）
自动驾驶控制最核心的简化模型——把四轮车辆等效为「前后轮连线」的自行车：

- **状态**：`(x, y, θ)`（位置 + 航向角）
- **控制输入**：`(v, δ)`（车速 + 前轮转角）
- 运动学关系：
  ```
  ẋ = v·cos(θ)
  ẏ = v·sin(θ)
  θ̇ = v/L · tan(δ)      # L 为轴距
  ```
- 含义：转向角越大或车速越高，航向角变化越快。

> 除了运动学模型，工程上还会用**动力学模型**（考虑轮胎侧偏、质量、惯量），在高速、急转向时更准确。

## 2. 经典跟踪控制算法

### PID（比例-积分-微分）
- **原理**：根据误差（如横向偏差）输出控制量：`u = Kp·e + Ki·∫e·dt + Kd·de/dt`。
- 优点：简单、易实现、调参直观。
- 缺点：直接用在车辆跟踪上性能有限，通常作为入门或与其他方法结合。
- **适用**：速度控制、简单场景、作为基础。

### Pure Pursuit（纯追踪）
- **原理**：在目标轨迹上选取一个「前视点」（前瞻距离 ld），计算车辆到该点的圆弧转角，控制车辆沿圆弧追踪。
  ```
  δ = atan(2·L·sin(α) / ld)
  ```
- 优点：实现简单、鲁棒，适合低速、曲率平滑的路径。
- 缺点：前瞻距离需要调参，高速性能一般。
- **适用**：移动机器人、低速 AGV、入门追踪控制。

### Stanley（斯坦利）
- **原理**：同时考虑**横向偏差**与**航向偏差**，计算前轮转角，收敛快、性能好。
  ```
  δ = θe + atan(k·e / v)
  ```
  - `θe`：航向角偏差
  - `e`：横向偏差
- **优点**：比 Pure Pursuit 更精确、鲁棒性更好。
- **适用**：自动驾驶经典跟踪算法，适合结构化道路。

### LQR（线性二次调节器）
- **原理**：把车辆模型线性化，求解使「状态偏差 + 控制量」加权最小的反馈增益。
- **优点**：理论清晰、计算量小、适合高速稳定性控制。
- **适用**：横向/纵向耦合控制、高速场景。

### MPC（模型预测控制）—— 主流之选
- **原理**：在每个控制周期，基于车辆模型**预测未来 N 步**，在约束下优化出一段最优控制序列，只执行第一步，滚动迭代。
  ```
  min  Σ (预测状态-目标轨迹的偏差) + 控制量代价 + 避障惩罚
  s.t. 车辆模型约束 / 执行器限幅 / 安全距离
  ```
- **优点**：能同时处理**多目标**（跟踪+避障+舒适）与**约束**，性能最好。
- **缺点**：计算量大，对模型准确性和实时性要求高。
- **适用**：自动驾驶主流控制器、复杂/高速场景。

## 3. 控制算法对比

| 算法 | 复杂程度 | 实时性 | 性能/鲁棒性 | 典型场景 |
| --- | --- | --- | --- | --- |
| PID | 低 | 极高 | 一般 | 基础/速度控制 |
| Pure Pursuit | 低 | 高 | 中 | 低速、简单路径 |
| Stanley | 中 | 高 | 中高 | 结构化道路 |
| LQR | 中 | 高 | 高 | 高速、耦合控制 |
| MPC | 高 | 中 | 极高 | 自动驾驶主流 |

## 4. 纵向控制（油门/刹车）

除了横向转向，还需要**纵向控制**来匹配目标速度与加速度：

- **上层**：根据轨迹目标速度 + 跟车距离，计算出目标加速度。
- **底层**：把加速度指令映射为油门开度 / 刹车压力。
- 常用：PID、基于模型的前馈 + 反馈、坡道补偿等。

## 5. 控制闭环工程要点

- **坐标统一**：控制计算前先把车辆状态与目标轨迹统一到同一坐标系。
- **反馈频率**：控制周期通常 10~100 Hz，需保证实时性。
- **底盘接口**：与线控底盘对接，输出方向盘转角 / 油门 / 刹车指令，读取实际执行反馈。
- **标定与补偿**：转向死区、油门非线性、轮胎侧偏等都需要工程标定。
- **安全保护**：超速、超转角、通信中断时的降级与急停逻辑。
