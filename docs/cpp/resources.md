# 精选书单与资源

## 📚 经典书籍

### 入门
| 书籍 | 适合人群 |
| --- | --- |
| 《C++ Primer》（第 5 版） | 零基础到进阶的首选教材，系统全面 |
| 《C++ 程序设计语言》（Bjarne Stroustrup） | C++ 之父著，权威参考 |
| 《Effective C++》 | 写出高质量 C++ 的 55 个习惯 |

### 进阶
| 书籍 | 主题 |
| --- | --- |
| 《Effective Modern C++》 | 现代 C++（11/14）最佳实践 |
| 《Effective STL》 | STL 使用技巧 |
| 《深度探索 C++ 对象模型》 | 对象模型、内存布局底层原理 |
| 《C++ Templates》 | 模板与泛型编程深入 |
| 《C++ Concurrency in Action》 | 并发编程权威指南 |

## 📌 实战项目思路

1. **文本处理工具**：实现一个词频统计、正则匹配工具
2. **数据结构库**：实现 vector、list、hashmap
3. **简单解释器**：实现四则运算计算器
4. **多线程下载器**：体验并发编程
5. **2D 图形引擎**：结合 CMake 构建工程
6. **机器人控制模块**：结合 [ROS/ROS2 知识库](../ros2/README.md) 实战
