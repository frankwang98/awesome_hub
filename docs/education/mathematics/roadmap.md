# 数学学习路径：从基础到建模

> 学数学不是收集公式，而是学习用数量、结构、变化和逻辑描述问题。

## 知识地图

```text
数与运算
  ↓
代数与方程
  ↓
函数与变化
  ↓
几何与空间
  ↓
概率统计与数据
  ↓
建模、证明与数学思想
```

## 建议顺序

| 阶段 | 必须掌握 | 用来解决什么问题 |
| --- | --- | --- |
| 1. 数与运算 | 分数、比例、百分数、估算、单位 | 比较数量、判断量级、处理日常数据 |
| 2. 代数 | 式、方程、不等式、因式分解 | 用符号表达未知量和约束 |
| 3. 函数 | 变量、坐标、一次/二次函数、图像 | 理解“一个量如何随另一个量变化” |
| 4. 几何 | 相似、勾股、面积体积、坐标几何 | 描述形状、位置、距离与空间关系 |
| 5. 概率统计 | 平均数、分布、概率、抽样、相关性 | 读懂数据并避免被偶然性误导 |
| 6. 数学思想 | 分类、化归、函数、数形结合、反证 | 选择方法、组织推理并建立模型 |

## 学习检查

每学完一个主题，至少能回答：

1. 这个概念描述的对象是什么？
2. 它与前一个概念有什么关系？
3. 能不能画图、举例或用日常语言解释？
4. 题目换一个场景后，方法还适用吗？
