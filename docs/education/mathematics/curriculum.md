# 数学全学段核心地图

> 适用范围：小学 → 高中 → 成年人基础重建 · 状态：Foundational · 最后复核：2026-09-26

数学不是按年级堆知识点，而是逐步获得五种能力：**数感、符号表达、空间想象、数据判断、逻辑推理**。下表覆盖小学到高中的核心内容；每个单元将逐步拆为“讲解 + 例子 + 练习 + 解析”。

## 小学：数量与直觉

| 单元 | 必须理解 | 现实连接 |
| --- | --- | --- |
| 数与运算 | 自然数、整数、小数、四则运算、估算 | 购物、时间、预算、数量级判断 |
| 分数与百分数 | 部分和整体、通分、比例、增长率 | 折扣、利率、配方、投票与统计 |
| 量与单位 | 长度、面积、体积、质量、时间、单位换算 | 测量房间、做饭、出行、读表 |
| 图形与几何 | 周长、面积、体积、角、对称、坐标直觉 | 平面设计、空间规划、地图 |
| 数据初步 | 表格、条形图、折线图、平均数 | 阅读新闻图表、记录变化 |

## 初中：从具体数量到关系

| 单元 | 必须理解 | 现实连接 |
| --- | --- | --- |
| 有理数与实数 | 相反数、绝对值、平方根、数轴 | 温度、收支、误差、距离 |
| 代数式与整式 | 用字母表示数量，化简与因式分解 | 用模型表达成本、面积、规律 |
| 方程与不等式 | 未知量、约束、解的意义 | 预算边界、速度问题、方案选择 |
| 一次 / 二次函数 | 变量、图像、斜率、顶点、交点 | 套餐、利润、运动、最优问题 |
| 几何证明 | 全等、相似、勾股、圆、变换 | 测量不可直接测量的距离与形状 |
| 概率与统计 | 样本、平均数、中位数、概率、相关性 | 抽样调查、风险、数据误读 |

## 高中：结构、变化与抽象

| 单元 | 必须理解 | 现实连接 |
| --- | --- | --- |
| 集合与逻辑 | 分类、充分必要条件、命题 | 程序条件、论证与定义边界 |
| 函数体系 | 指数、对数、幂函数、三角函数、反函数 | 增长、衰减、周期、尺度变化 |
| 导数与变化率 | 瞬时变化、单调性、极值、最优化 | 速度、边际变化、优化决策 |
| 数列 | 递推、等差、等比、求和 | 分期、复利、离散增长 |
| 向量与解析几何 | 位置、方向、坐标、直线与圆锥曲线 | 导航、图形、物理中的方向与轨迹 |
| 立体几何 | 空间关系、距离、角度、投影 | 工程图、空间定位、三维建模 |
| 概率统计 | 条件概率、随机变量、分布、抽样推断 | 风险评估、实验、数据分析 |

## 学习顺序

```text
数感与运算
↓
比例、分数、百分数与单位
↓
代数式、方程、不等式
↓
函数与图像
↓
几何与证明
↓
概率统计
↓
高中函数、导数、向量与综合建模
```

不要跳过比例、方程和函数直接学导数或高等数学；它们是理解“变化”和“模型”的语言基础。

## 每个单元的完成标准

1. 能用自己的话说明概念在描述什么；
2. 能在表格、图像、公式和现实语言之间转换；
3. 能完成基础题、变式题和一个真实情境题；
4. 能说出方法什么时候不适用。
