# 数学诊断练习与解析

> 适用范围：小学 → 高中核心衔接 · 状态：Foundational · 最后复核：2026-09-26

这些题不是题库，而是用来判断概念是否真正掌握。先独立作答，再看解析；若错了，记录错在概念、计算、条件还是建模。

## 1. 小学：百分数与变化

**题目**：一件商品先打八折，再在折后价基础上减 10%。最终价格是原价的百分之多少？

<details>
<summary>参考答案与解析</summary>

最终价格是 `80% × 90% = 72%`，即原价的 72%。

“打八折再减 10%”不是“总共减 30%”，因为第二次减少的基数已经变为折后价。
</details>

## 2. 初中：方程的实际意义

**题目**：某网约车起步价 14 元，之后每千米 2.5 元。小李支付了 39 元，行驶了多少千米？假设所有路程都按同一标准计费。

<details>
<summary>参考答案与解析</summary>

设行驶 `x` 千米，则：

```text
14 + 2.5x = 39
2.5x = 25
x = 10
```

行驶 10 千米。方程左边不是抽象符号：`14` 是固定费用，`2.5x` 是随距离变化的费用。
</details>

## 3. 初中：函数与图像

**题目**：函数 `y = -2x + 6` 的图像与坐标轴分别交于哪里？它随 `x` 增大如何变化？

<details>
<summary>参考答案与解析</summary>

- 与 `y` 轴交点：令 `x = 0`，得 `(0, 6)`；
- 与 `x` 轴交点：令 `y = 0`，得 `x = 3`，即 `(3, 0)`；
- 系数 `-2` 表明：`x` 每增加 1，`y` 减少 2，因此图像从左向右下降。

不能把 `6` 理解成“斜率”；它是 `x = 0` 时的初始值。
</details>

## 4. 初中：概率与样本

**题目**：从装有 3 个红球、2 个蓝球的盒中随机取 1 个球，取到红球的概率是多少？如果连续取 100 次，红球是否一定恰好出现 60 次？

<details>
<summary>参考答案与解析</summary>

单次取红球的概率为 `3 / 5 = 60%`。连续 100 次时，红球出现次数**不一定**恰好是 60；60 是长期重复试验中次数比例趋近的目标，不是每一小段试验的保证。
</details>

## 5. 高中：指数增长

**题目**：某账户有 10,000 元，每年增长 5%，不额外存取。两年后的余额是多少？为什么不能写成 `10,000 × (1 + 10%)`？

<details>
<summary>参考答案与解析</summary>

```text
10,000 × 1.05² = 11,025
```

第二年的 5% 是按第一年增长后的 10,500 元计算的，因此是复合增长。`1 + 10%` 忽略了“利息也继续增长”的部分。
</details>

## 6. 高中：导数与最优化直觉

**题目**：一个面积为 `A(x) = -x² + 10x` 的矩形面积随边长 `x` 变化。在哪个 `x` 附近面积最大？

<details>
<summary>参考答案与解析</summary>

抛物线开口向下，顶点横坐标为：

```text
x = -b / (2a) = -10 / (2 × -1) = 5
```

所以 `x = 5` 时面积最大。若使用导数，`A'(x) = -2x + 10`；令它为 0，同样得到 `x = 5`。导数为 0 表示此刻的瞬时变化率为 0，但还需结合函数形状确认是最大而非最小。
</details>
