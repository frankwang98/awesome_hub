# 古诗文：篇目、精讲与背诵

> 适用范围：小学 → 高中 → 通识积累 · 状态：Current Valid · 最后复核：2026-09-26

这里不是把古诗文全文堆进仓库，而是为每个重点篇目提供可学习的入口：**文本来源、背景、关键字词、画面 / 结构、主题边界、背诵提示、练习与解析**。

## 每篇的固定结构

```text
准确文本与来源
↓
背景与读前问题
↓
关键字词 / 句式
↓
画面、结构、语言与情感
↓
背诵提示
↓
练习、参考答案与解析
```

古诗文多数属于公共领域作品，但本库仍优先链接可靠原文来源；现代教材的注释、译文和解析不直接复制。
