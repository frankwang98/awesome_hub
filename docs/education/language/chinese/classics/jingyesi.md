# 《静夜思》：由月光到思乡

> 学段 / 适用范围：小学积累 → 初高中复习 → 通识欣赏  
> 状态：Foundational · 最后复核：2026-09-26

## 原文

李白《静夜思》：

> 床前明月光，疑是地上霜。  
> 举头望明月，低头思故乡。

## 读前问题

四句小诗为什么能让“月光”自然变成“思乡”？阅读时重点看视线和动作如何变化。

## 关键字词

| 词语 | 理解 |
| --- | --- |
| 疑 | 仿佛、好像；不是经过论证后的怀疑 |
| 举头 / 低头 | 连续的动作，也形成由外物到内心的转折 |
| 思 | 思念；由眼前景物触发 |

## 画面、结构与情感

前两句先写夜里所见：月光洒在床前，明亮清冷，像地上铺了一层霜。这里的“疑”保留了初醒时的朦胧感。

后两句把镜头从“床前”转向天空，再收回内心：抬头看月，低头想起故乡。诗没有解释故乡在哪里、离别多久，却用一个极自然的动作链，让视觉感受转化为思念。

主题是思乡，但不宜把它解释成强烈悲痛；诗的力量正在于平静、日常而普遍的触发。

## 背诵提示

```text
眼前月光 → 像霜的错觉 → 抬头望月 → 低头思乡
```

记住的是一条视线与情感的路径，而不是孤立的四行字。

## 练习与解析

### 练习 1

“举头”和“低头”只是在交代动作吗？

<details>
<summary>参考答案与解析</summary>

不只如此。两个相反方向的动作把诗的结构推进：先面对外部的明月，再回到内心的故乡。“望”与“思”也因此被连接起来。
</details>

### 练习 2

为什么不宜把“疑是地上霜”直接解释为“真的下霜了”？

<details>
<summary>参考答案与解析</summary>

“疑是”说明这是月光带来的视觉错觉。它描写月光的明亮、清冷和夜色的朦胧，不是在报告天气。
</details>

### 练习 3

用 60–100 字说明本诗如何由景入情。

<details>
<summary>参考答案与解析</summary>

示例：诗人先写床前月光，因明亮清冷而仿佛地上结霜；接着由低处的月光转向高处的明月。抬头看月的动作触发了对远方故乡的思念，因此写景和抒情之间没有生硬的跳跃。
</details>
