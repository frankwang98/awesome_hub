# 语文全学段核心地图

> 适用范围：小学 → 高中 → 成年人基础重建 · 状态：Foundational · 最后复核：2026-09-26

语文的核心不是记住很多“标准答案”，而是形成**准确阅读、有效表达、审美感受与文化理解**。教材篇目会随版本变化，因此本库以能力和经典类型组织，不复制特定教材。

## 小学：语言感受与基本表达

| 单元 | 必须形成的能力 | 建议材料类型 |
| --- | --- | --- |
| 字词与句子 | 准确理解词义，写通顺句子 | 日常叙事、说明文字 |
| 朗读与背诵 | 感受节奏，积累语言 | 古诗、短文、儿歌与经典片段 |
| 叙事阅读 | 说清人物、事件、顺序与感受 | 童话、寓言、记叙文 |
| 基础表达 | 围绕一件事写清经过和感受 | 日记、看图写话、书信 |
| 常用古诗文 | 理解常见意象、情感和必要注释 | 唐诗宋词、浅近文言片段 |

## 初中：篇章理解与表达结构

| 单元 | 必须形成的能力 | 关键问题 |
| --- | --- | --- |
| 现代文阅读 | 概括、找依据、分析结构和表达效果 | 作者说什么，如何推进？ |
| 叙事与散文 | 人物、线索、描写、情感 | 什么细节承担了主题？ |
| 议论与说明 | 观点、论据、逻辑、说明方法 | 结论凭什么成立？ |
| 文言文 | 实词、虚词、句式、断句与语境 | 这句话在当时的语境中是什么意思？ |
| 古诗词 | 意象、画面、情感、手法 | 景、情、语言如何相互作用？ |
| 写作 | 立意、选材、结构、修改 | 如何让读者愿意并能够理解？ |

## 高中：复杂文本与独立表达

| 单元 | 必须形成的能力 | 关键问题 |
| --- | --- | --- |
| 论述类文本 | 概念界定、论证链、隐含前提 | 作者的推理有没有跳步？ |
| 文学类文本 | 叙述视角、语言、形象、主题张力 | 作品如何制造意义而非只“讲故事”？ |
| 古代文化与文言 | 语法、史传、论说、思想背景 | 语言形式如何连接历史与思想？ |
| 整本书阅读 | 结构、人物关系、时代语境、批评 | 一部作品怎样回应其时代和人？ |
| 写作与论证 | 论点、材料、反驳、段落与修订 | 如何用有限文字建立可信表达？ |

## 经典作品如何进入本库

每篇作品优先提供：背景、必要短引文、关键字词或句式、结构、主题、常见误解与练习。推荐按作品类型而非教材版本积累：

```text
古诗词：山水、送别、边塞、咏史、咏物、人生感怀
文言文：叙事、写景、论说、史传、寓言
现代文：叙事、散文、说明、评论、演讲
整本书：小说、诗歌、戏剧、非虚构作品
```

涉及受版权保护的现代作品，只做原创分析、必要短引文与公开来源链接，不转载全文。

## 学习顺序

```text
字词与句子
↓
段落与篇章结构
↓
现代文阅读
↓
古诗文理解
↓
写作与修改
↓
文学、文化与复杂文本
```
