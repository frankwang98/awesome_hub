# 英语学习路径：理解与表达优先

> 英语学习的核心是把输入变成可理解的信息，再把想法表达出来；词汇和语法是工具，不是终点。

## 四项能力

| 能力 | 核心任务 | 起步方式 |
| --- | --- | --- |
| 词汇 | 认识高频词，并知道它们常和什么搭配 | 在句子中学习，不孤立背词表 |
| 语法 | 理解句子如何表达时间、关系、条件和态度 | 先掌握主干，再理解修饰结构 |
| 阅读 | 从句子到段落获取信息与观点 | 精读短文，复述段落 |
| 写作与表达 | 用简单但准确的句子说明事实和想法 | 日记、摘要、邮件与改写 |

## 建议顺序

```text
高频词与基本句型
  ↓
时态、语态、从句与非谓语
  ↓
短文阅读与复述
  ↓
段落写作与常见表达
  ↓
听说输入与真实交流
```

## 语法学习检查

看到一个句子时，能够找出：

1. 主语、谓语和宾语或表语。
2. 动作发生的时间与状态。
3. 修饰信息属于哪个词或哪个句子成分。
4. 连接词表达的是并列、转折、原因、条件还是结果。

## 第一批内容方向

核心句型、时态地图、高频动词、名词与冠词、从句、阅读策略、写作段落与常用表达。

## 学完即练

阅读知识条目后，进入 [English Practice 互动练习](practice-lab.md)：先完成词汇输入，再学习一项语法，最后用造句练习把规则变成表达。
