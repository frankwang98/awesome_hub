# 英语句子的主干：先找到谁做了什么

> 范围：英语语法基础 · 状态：Current Valid · 最后复核：2026-09-26

读长句时，第一步不是逐词翻译，而是找到句子的核心：**谁（或什么）做了什么，是什么，或处于什么状态**。

## 五种常见主干

| 类型 | 结构 | 例句 |
| --- | --- | --- |
| 主语 + 动词 | S + V | Birds fly. |
| 主语 + 动词 + 宾语 | S + V + O | Students read books. |
| 主语 + 系动词 + 表语 | S + Link V + C | The idea is useful. |
| 主语 + 动词 + 间接宾语 + 直接宾语 | S + V + IO + DO | She gave me a note. |
| 主语 + 动词 + 宾语 + 补语 | S + V + O + C | They made the room quiet. |

`S` 是主语，`V` 是谓语动词，`O` 是宾语，`C` 是补语或表语。先掌握它们的作用，比背术语更重要。

## 长句拆解流程

```text
先圈谓语动词
↓
向左找主语
↓
向右判断有没有宾语、表语或补语
↓
把介词短语、从句、非谓语先标成“修饰信息”
↓
最后再按中文表达习惯重组
```

## 例子

> The student **who sits near the window** **finished** the report **before lunch**.

先取主干：`The student finished the report.`

- `who sits near the window`：修饰 `student` 的定语从句；
- `before lunch`：补充完成报告的时间。

因此可理解为：“坐在窗边的那名学生在午饭前完成了报告。”

## 常见误区

- **看到第一个动词就当谓语**：从句和非谓语中也会有动词形式。
- **把长定语当主干**：先找名词中心词，再看后面的修饰成分。
- **逐词按中文顺序翻译**：先还原逻辑关系，表达时再调整语序。

## 自检练习

给下面句子画出主干，并标出修饰信息：

> The book that I borrowed from the library explains how bridges are built.

参考：主干是 `The book explains ...`；`that I borrowed from the library` 修饰 `book`；`how bridges are built` 是 `explains` 的内容。
