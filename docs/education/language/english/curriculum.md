# 英语全学段核心地图

> 适用范围：小学 → 高中 → 成年人基础重建 · 状态：Foundational · 最后复核：2026-09-26

英语学习的目标是理解与表达。词汇、语法、阅读、听力、写作和口语不是六条平行赛道，而是在同一批真实语言材料中反复配合。

## 小学：声音、常用词与简单交流

| 单元 | 必须形成的能力 | 练习方式 |
| --- | --- | --- |
| 语音与拼读 | 字母、常见发音、重音与基础拼读 | 听读模仿、拼读短词 |
| 高频词块 | 人、物、动作、时间、地点与常用表达 | 在短句和对话里积累 |
| 基本句型 | 介绍、询问、喜欢、拥有、位置、日常活动 | 看图说话、替换练习 |
| 简短阅读 | 从图片和句子获得明确信息 | 标题、关键词、问答 |
| 基础书写 | 写出完整、可理解的简单句 | 日记、留言、介绍 |

## 初中：句子、段落与信息理解

| 单元 | 必须形成的能力 | 关键问题 |
| --- | --- | --- |
| 词汇与搭配 | 高频动词、名词、形容词、固定搭配 | 这个词通常和谁一起出现？ |
| 核心语法 | 时态、语态、名词、冠词、代词、比较 | 发生在何时、谁做了什么？ |
| 复杂句 | 从句、非谓语、连接词、修饰关系 | 哪部分是主干，哪部分是补充？ |
| 阅读 | 找主旨、细节、指代与推断 | 证据在哪里？ |
| 写作与口语 | 描述、叙事、说明、简单观点表达 | 能否用段落组织信息？ |

## 高中：复杂表达与真实沟通

| 单元 | 必须形成的能力 | 关键问题 |
| --- | --- | --- |
| 词汇深度 | 词义辨析、词族、语域与搭配 | 这个词在此处带什么语气？ |
| 高级语法 | 虚拟、倒装、强调、复杂从句与衔接 | 结构怎样影响重点和态度？ |
| 阅读策略 | 论证结构、语气、修辞、跨段推断 | 作者的立场如何被表达？ |
| 写作 | 段落主题句、证据、衔接、修订 | 读者能否快速理解我的主张？ |
| 听说 | 真实语速、信息筛选、讨论与陈述 | 能否听懂重点并清楚回应？ |

## 学习顺序

```text
语音与高频词
↓
基本句型与句子主干
↓
时态、词类与常见修饰
↓
从句、非谓语与段落阅读
↓
写作、听说与真实交流
↓
复杂文本、语域与独立表达
```

## 每个主题的完成标准

1. 能在短句中识别该结构或词汇；
2. 能解释它表达的时间、关系或语气；
3. 能在自己的句子里正确使用；
4. 能在短文中读懂并迁移。
