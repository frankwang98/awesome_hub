# 学习、练习与复习

> 状态：Current Valid · 最后复核：2026-09-26

知识库提供地图，但真正的掌握发生在主动回忆、练习和间隔复习中。

## 一个主题的最小闭环

```text
读懂一个概念
↓
合上资料，用自己的话写出它
↓
完成 2–5 个由浅到深的问题
↓
记录错误的原因
↓
在之后的日期重新回忆
```

## 练习要解决什么

| 练习类型 | 要验证的能力 | 例子 |
| --- | --- | --- |
| 回忆题 | 能否不看资料说出核心概念 | “函数的自变量和因变量分别是什么？” |
| 变式题 | 能否在新情境中识别同一模型 | 改变题目背景后判断变量关系 |
| 解释题 | 能否说明为什么 | “为什么这个条件不能省略？” |
| 综合题 | 能否把多个概念连起来 | 从现象选模型、计算并解释结果 |

## 复习节奏

不必机械追求固定天数，但可以采用这个轻量节奏：

```text
当天：完成首次理解与练习
1–3 天后：不看资料回忆
一周后：做一道变式题
一个月后：与相邻知识一起复盘
```

如果回忆失败，不是“重新读一遍”就结束：先定位是概念不清、条件遗漏、计算不熟，还是不会把知识迁移到新题目，再针对性补一小段。

## 错题 / 误解记录模板

```text
主题：
我原来的判断：
哪里错了：
正确的判断条件：
下次如何快速识别：
```

错误记录只保留会反复出现、值得复盘的误解；不要把它变成无法回看的题目仓库。

## 与本仓库的关系

每篇成熟条目都应至少提供：

1. 一段可主动回忆的核心内容；
2. 一个贴近概念的例子；
3. 一组练习或自检问题；
4. 指向下一主题的链接。
