# 🧭 通识教育知识地图

这里先建立学习路径，再逐步填入高价值内容。

## 从哪里开始

- 想补基础：从 [成年人基础重建路线](learning/adult-foundations.md) 进入。
- 想系统学一个学科：先读对应入口，再沿学习路径推进。
- 想把一个知识点真正记住：配合 [学习、练习与复习](learning/practice-and-review.md) 完成闭环。

## 互动练习场

知识条目负责讲清楚，练习场负责把它变成可回忆、可表达的能力。

| 模块 | 现在可以做什么 | 入口 |
| --- | --- | --- |
| English Practice | 词汇、核心语法、造句、朗读与录音 | [进入英语互动练习](language/english/practice-lab.md) |
| Chinese Practice | 古诗词关键句默写与理解提示 | [进入语文互动练习](language/chinese/practice-lab.md) |

## 第一阶段：基础重建

适合需要重新打基础的成年人：

```text
语文：阅读与表达
英语：高频词汇与核心语法
数学：数、式、方程、函数与几何
科学：观察、模型、实验与因果
```

## 第二阶段：理解世界

```text
历史与地理 → 理解时间、空间和文明
科学与数学 → 理解规律、证据和模型
文学与哲学 → 理解语言、思想和价值
经济、法律、社会 → 理解公共生活和制度
```

## 知识域

- Language：Chinese / English

- [Science 科学](science/README.md)：Physics / Chemistry / Biology

- [General Knowledge 通识](general/README.md)：Economics / Law / Society / Art / Life
