# Science 科学

科学部分关注的不是公式清单，而是用观察、模型、实验与证据理解自然世界。

## 三条主线

| 领域 | 核心问题 | 首批内容方向 |
| --- | --- | --- |
| [Physics 物理](physics/README.md) | 事物如何运动、相互作用与传递能量？ | 力学、能量、电磁、实验模型 |
| [Chemistry 化学](chemistry/README.md) | 物质由什么构成、怎样变化？ | 原子结构、化学反应、物质性质 |
| [Biology 生物](biology/README.md) | 生命如何运作、遗传、演化与互相影响？ | 细胞、遗传、进化、生态 |

## 建议学习顺序

```text
现象与测量
↓
模型与变量
↓
定律 / 原理
↓
实验、计算与证据
↓
把模型用回真实问题
```

每个主题都应明确模型适用的条件与边界；会代入公式不等于理解模型。
