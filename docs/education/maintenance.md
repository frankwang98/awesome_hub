# 内容维护与可信度

Education Hub 的目标不是追求条目数量，而是让读者知道一篇内容是否适合现在学习、适用于什么范围、何时需要重新核对。

## 内容状态

| 状态 | 含义 | 适用内容 |
| --- | --- | --- |
| `Foundational` | 长期稳定的基础概念，仍应在有明显表述问题时修订 | 基础数学、语法、经典阅读方法、基础科学模型 |
| `Current Valid` | 已按当前资料核对，可正常使用 | 方法、框架、相对稳定的知识条目 |
| `Needs Review` | 可能有更新、争议或解释不足，暂不作为定论 | 法律、健康、公共议题、数据类内容 |
| `Historical Context` | 用于理解历史背景，不等于今天仍然适用 | 历史制度、旧理论、过往案例 |

## 每篇条目至少说明

```text
学段 / 适用范围
状态
最后复核日期
```

涉及事实主张、统计数据、法律、健康、公共政策或版权材料时，再添加“来源与延伸阅读”。链接应尽量指向原始机构、课程标准、经典著作或可核查的一手资料。

## 复核节奏

| 内容类型 | 建议复核 |
| --- | --- |
| 数学、基础语法、经典作品导读 | 有重大修订或发现表述问题时 |
| 科学普及、社会与人文解释 | 每 12–24 个月，或有重要新共识时 |
| 法律、健康、公共政策、统计数据 | 发布前核查；每 6–12 个月复核 |

## 维护顺序

1. 先维护学习路径与已有核心条目；
2. 修正错误、补清适用边界，再新增页面；
3. 将仍有价值但过时的内容标为 `Historical Context` 或 `Needs Review`，不静默删除其背景；
4. 用更新说明记录重大修订，避免读者误以为旧结论仍然有效。

## 不收录什么

- 未核实的“学习秘诀”、伪科学或把个例包装成普遍规律的内容；
- 大段复制的教材、试卷、文章或受版权保护的文本；
- 缺少范围与来源的高风险建议。
