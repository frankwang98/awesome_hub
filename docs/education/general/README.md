# General Knowledge 通识

通识不是零散的“冷知识”，而是每个人在公共生活、工作与个人决策中反复会用到的基本框架。

## 主题

| 领域 | 关注什么 |
| --- | --- |
| [Economics 经济](economics/README.md) | 激励、选择、市场与公共资源 |
| [Law 法律](law/README.md) | 权利、义务、规则与风险意识 |
| [Society 社会](society/README.md) | 媒介、组织、公共议题与信息判断 |
| [Art 艺术](art/README.md) | 作品、形式、历史与审美经验 |
| [Life 生活](life/README.md) | 健康、沟通、决策与生活能力 |

## 内容原则

- 先理解基本概念与适用场景，再讨论立场与案例。
- 涉及法律、健康、政策、数据等时效性内容，必须列出来源与复核日期。
- 不把一般性解释替代专业意见；高风险问题应指向权威来源或专业人士。
