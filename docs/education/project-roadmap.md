# Education Hub 建设路线

这是一份内容建设清单，不是承诺一次性填满的教材目录。只有内容达到可解释、可练习、可维护的标准，才进入正式知识区。

## Phase 1 · Foundation（当前）

- [x] 建立按学科组织的知识地图
- [x] 提供统一条目模板、内容状态和复核规则
- [x] 建立成年人基础重建路线
- [x] 为语文、英语、数学提供学习路径与首篇示例
- [x] 为科学、人文、通识建立总入口

## Phase 2 · Core Learning Paths

优先建立成年人最常重学、最能产生迁移价值的内容：

- [ ] 语文：现代文阅读、古诗文阅读、基础写作
- [ ] 英语：高频词、时态、从句、阅读与写作
- [ ] 数学：数与式、方程、不等式、函数、几何、统计概率
- [ ] 科学：测量与模型、力与能量、物质与反应、生命与生态

每个主题至少包含：为什么学、核心概念、一个例子、常见误解、最小练习和下一步。

## Phase 3 · Understand the World

- [ ] 历史：时间线、文明、制度与因果解释
- [ ] 地理：地球系统、气候、区域与人地关系
- [ ] 文学 / 哲学：作品、概念与论证
- [ ] 经济 / 法律 / 社会：基础模型、公共规则和信息判断
- [ ] 生活：健康、沟通与决策的可靠基本框架

该阶段要特别标明资料来源、观点边界与复核日期。

## Phase 4 · Learning System

- [ ] 为成熟条目补充分层练习与解析
- [ ] 形成可复用的自测、错题和间隔复习流程
- [ ] 将前置与后续知识串成可导航的学习图
- [ ] 评估基于本仓库的学习助手 / AI 问答，但不让 AI 取代来源核查

## 完成标准

一篇条目不是“有 Markdown 文件”就完成。至少满足：

```text
范围清楚
↓
解释正确且有边界
↓
有能检验理解的例子或练习
↓
知道下一步学什么
↓
状态、来源与复核日期可追踪（适用时）
```
