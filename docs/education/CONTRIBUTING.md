# 贡献与写作规范

## 内容原则

- 写“必须理解的知识”，不搬运整本教材。
- 用自己的解释、图示、例子和原创练习帮助学习。
- 经典文本仅使用必要短引文，并标注作者、作品和来源。
- 事实、法律、健康、社会议题等内容必须给出可靠来源和最后复核日期。
- 版本敏感或存在争议的内容应明确适用范围，不把暂时结论写成永恒事实。

## 单篇条目建议

```markdown
# 主题名称

> 学段 / 适用范围：小学 / 初中 / 高中 / 通识
> 状态：Foundational / Current Valid / Needs Review / Historical Context
> 最后复核：YYYY-MM-DD

## 为什么要学
## 核心概念或经典内容
## 解释与例子
## 易错点
## 练习与解析
## 关联知识
## 来源与延伸阅读
```

## 维护方式

先完善各学科的知识地图和最短学习路径；单个主题在有可靠内容时再建立页面。避免为了“目录齐全”创建大量空文章。

状态定义和复核节奏见[内容维护与可信度](maintenance.md)。
