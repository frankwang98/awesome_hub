# 《周易》与八卦

## 先区分经与传

《周易》的经文包括六十四卦的卦辞和爻辞，原与占筮实践密切相关；《易传》（“十翼”）则提供了哲学化阐释。两者形成于不同历史层次。

## 八卦速查

| 卦 | 自然象征 |
| --- | --- |
| 乾 ☰ | 天 |
| 坤 ☷ | 地 |
| 震 ☳ | 雷 |
| 巽 ☴ | 风 |
| 坎 ☵ | 水 |
| 离 ☲ | 火 |
| 艮 ☶ | 山 |
| 兑 ☱ | 泽 |

三爻组成一卦，两个三爻卦上下相叠可组成六爻的六十四卦。

## 如何入门

1. 认识阴爻（断线）和阳爻（实线）。
2. 认识八卦的三爻结构和基本象征。
3. 区分卦象、卦辞、爻辞、易传。
4. 选择乾、坤等卦，阅读原文与不同注释。

《周易》与道家有思想交汇，但不等于《道德经》或八字命理。
