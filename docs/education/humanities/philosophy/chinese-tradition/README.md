# 中国传统思想与易学 · 学习地图

> 从哲学思想、古代历法到传统术数，理解概念的来历、结构与边界。

## 先分清四个领域

- **道家哲学**：以《老子》《庄子》为核心，关注道、自然、无为与自由。
- **易学**：围绕《周易》及历代解释发展出的卦象与变化思想。
- **干支历法**：十天干、十二地支、六十甲子、节气和传统纪时。
- **命理术数**：八字、六亲、十神等历史文化实践；预测效果缺乏可靠科学验证。

它们有交叉和相互影响，但不是同一个体系，也不是道家的必修分支。

## 学习顺序

1. [阴阳与五行](yin-yang-wuxing.md)：分类、相生相克、传统方位与季节。
2. [天干地支与历法](stems-branches.md)：阴阳属性、生肖、时辰、节气与六十甲子。
3. [周易与八卦](yijing-bagua.md)：经传、八卦与六十四卦。
4. [道家思想](daoism.md)：老子、庄子及其重要命题。
5. [六亲与十神](liuqin-shishen.md)：以日主为中心推导十神，理解象意的边界。

## 学习方法

每个主题先读概念与例子，再试着不看表格推导一次。对“能量”“吉凶”“健康”“性格”类说法，区分古代象征体系与可检验的事实。
