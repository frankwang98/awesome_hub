# 六亲与十神：传统命理的关系模型

> 本篇解释术数的内部规则，不认可其能够科学预测人格、疾病、婚姻或财富。

## 六亲是什么

六爻等传统术数常见的“五类六亲”是父母、兄弟、子孙、妻财、官鬼。“六亲”是沿用的术语，分类本身为五类。

以“我”为中心：生我为父母、同我为兄弟、我生为子孙、我克为妻财、克我为官鬼。

相生：父母→兄弟→子孙→妻财→官鬼→父母。

相克：父母→子孙→官鬼→兄弟→妻财→父母。

## 十神推导规则

四柱八字以**日干（日主）**为中心，按五行生克及阴阳异同确定十神：

| 关系 | 同阴阳 | 异阴阳 |
| --- | --- | --- |
| 生我 | 偏印（枭神） | 正印 |
| 同我 | 比肩 | 劫财 |
| 我生 | 食神 | 伤官 |
| 我克 | 偏财 | 正财 |
| 克我 | 七杀（偏官） | 正官 |

口诀：生我印，同我比，我生食伤，我克财，克我官杀。

## 传统象意速查

| 十神 | 常见象征 |
| --- | --- |
| 正印 | 学习、保护、长辈 |
| 偏印 | 特殊知识、领悟 |
| 比肩 | 同伴、自我、竞争 |
| 劫财 | 同辈、资源竞争 |
| 食神 | 表达、技艺、享受 |
| 伤官 | 才华、创造、挑战规则 |
| 正财 | 稳定收入、经营 |
| 偏财 | 流动财富、商业机会 |
| 正官 | 规则、责任、管理 |
| 七杀 | 压力、竞争、权威 |

十神相生：比劫→食伤→财星→官杀→印星→比劫。

十神相克：食伤→官杀→比劫→财星→印星→食伤。

传统所谓“吉神”“凶神”是术数分类，不等于人物善恶；不同流派解释存在差异。

## 练习

1. 甲木遇壬水？答：偏印（水生木、同阳）。
2. 甲木遇己土？答：正财（木克土、异阴阳）。
3. 甲木遇庚金？答：七杀（金克木、同阳）。

## 证据边界

通过八字判断一个人必然暴力、婚姻不顺、患癌症，或穿某颜色衣服能够消灾，都没有可靠科学依据。学习时应将象意与可验证事实区分开。
