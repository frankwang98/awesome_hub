# 道家思想：老子与庄子

## 两个核心人物

- **老子**：传统上被视为《道德经》作者；文本形成及作者问题存在学术讨论。重要命题有“道法自然”“无为而无不为”“上善若水”。
- **庄子**：以《庄子》为代表，讨论逍遥、齐物、生命有限与精神自由。

## 六个核心概念

| 概念 | 入门解释 |
| --- | --- |
| 道 | 对万物根本依据及其运行方式的哲学思考 |
| 自然 | 自然而然、自身如此，并非仅指自然环境 |
| 无为 | 不妄为、不强制干预，不等于什么都不做 |
| 柔弱 | 柔韧、退让与不争也可能具有力量 |
| 反 | 事物变化、返回与反向转化 |
| 逍遥 | 不被固定评价和外在得失完全束缚 |

## 道家与道教

道家主要是思想传统；道教是包含经典、修行、仪式和组织的宗教传统。二者历史上相互影响，但不能等同。

## 推荐阅读

《道德经》选章 → 《庄子·逍遥游》→《齐物论》→《养生主》。

## 思考题

“无为”与“懒惰”有何区别？能否举出一个减少不必要干预反而改善结果的生活例子？
