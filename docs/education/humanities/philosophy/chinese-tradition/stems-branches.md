# 天干地支与传统历法

## 十天干

| 五行 | 阳 | 阴 |
| --- | --- | --- |
| 木 | 甲 | 乙 |
| 火 | 丙 | 丁 |
| 土 | 戊 | 己 |
| 金 | 庚 | 辛 |
| 水 | 壬 | 癸 |

按序号，奇数干为阳、偶数干为阴。

## 六十甲子

天干十个、地支十二个，按顺序同进一位，从甲子到癸亥，60组后循环。由于奇偶同步，不是 10×12=120 种有效组合。

## 节气与月建

传统四柱月建通常按十二个“节”切换，而非农历每月初一：寅月始于立春，卯月始于惊蛰，辰月始于清明，以此类推。

春：寅卯辰；夏：巳午未；秋：申酉戌；冬：亥子丑。节气基于太阳周年运动，与阴阳合历的农历月份不能混同。

## 练习

1. 辛属于什么五行、什么阴阳？答：阴金。
2. 午对应哪个生肖、哪个时段？答：马，约11–13时。
3. 为什么干支循环是60而非120？答：奇偶配对限制。
