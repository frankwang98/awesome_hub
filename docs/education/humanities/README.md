# Humanities 人文

人文部分帮助我们理解人、社会、文明与思想如何形成。它不追求记住所有年代或结论，而是建立可靠的背景、证据与解释框架。

## 四个入口

| 领域 | 关注什么 |
| --- | --- |
| [History 历史](history/README.md) | 时间、因果、制度、人物与文明 |
| [Geography 地理](geography/README.md) | 空间、环境、区域与人地关系 |
| [Literature 文学](literature/README.md) | 作品、语言、传统与阅读方法 |
| [Philosophy 哲学](philosophy/README.md) | 概念、论证、价值与思辨 |

## 阅读一个人文主题时

```text
背景与问题
↓
资料 / 作品 / 证据
↓
不同解释
↓
自己的判断与可讨论之处
```

区分事实、解释和评价，是长期学习人文的基本能力。
