# 任务规划与控制

具身 Agent 不应直接绕过安全控制器。更稳健的架构是“语义规划 + 几何规划 + 反馈控制”的分层协作。

```text
语言目标 → Agent / 行为树 → 子任务与约束
                         ↓
                   运动规划 / 轨迹优化
                         ↓
                    控制器与安全监控
```

- **任务层**：决定先拿什么、放到哪里、失败后如何恢复。
- **运动层**：检查碰撞、可达性、动力学与时间约束。
- **控制层**：跟踪轨迹，并用视觉、力觉持续纠偏。

更多传统规划控制基础可参考 [自动驾驶知识库](../autonomous-driving/README.md)。
