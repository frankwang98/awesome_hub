# 基础与系统框架

## 什么是“AI 连接物理世界”

语言模型擅长处理符号和文本；具身智能还必须处理传感器噪声、空间约束、动作延迟、安全边界与真实环境的变化。目标不是“会聊天的机器人”，而是能在约束下稳定完成任务的闭环系统。

```text
传感器 → 状态估计 / 世界表征 → 任务决策 → 运动规划 → 控制执行
   ↑                                                        ↓
   └────────────────── 观测、反馈、数据回流 ────────────────┘
```

## 三层职责

| 层级 | 典型职责 | 例子 |
| --- | --- | --- |
| 感知层 | 看见、定位、理解场景 | 检测、分割、姿态估计、VLM |
| 决策层 | 理解目标、拆分任务、选择策略 | LLM Agent、行为树、世界模型 |
| 执行层 | 生成安全、可执行的动作 | 规划器、轨迹优化、控制器 |

关键原则：高层 AI 负责语义与任务意图；底层确定性模块负责实时性、约束与安全。
