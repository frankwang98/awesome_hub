# 实用英语复习手册

母语汉语学习者专用，6 个月实用英语（听+说）学习包。**完全离线、零外部依赖**。

## 文件清单

| 文件 | 用途 | 何时用 |
|------|------|--------|
| `index.html` | 总入口 | 每次复习时打开 |
| `vocabulary.html` | 核心词汇 2000（**带会/不会标记**）| 每天 15 分钟 |
| `grammar.html` | 12 核心语法 | 学新语法时 |
| `sentence_practice.html` | **60 句造句 + 录音** | **每天 20 分钟** |
| `*.md` | 原文（编辑用） | 不想用 HTML 时 |
| `optional/anki_vocabulary.csv` | Anki 导入文件（不用可忽略）| 想用 Anki 时 |

## 推荐复习流程（每天 35 分钟）

**早晨 15 分钟 - 词汇：**
1. 打开 `vocabulary.html`
2. 顶部过滤栏选择 **"❌ 不会（重点复习）"**
3. 每个词行点 **🔊** 听音，回忆中文意思
4. 想起来的点 **○ → ✓**（会了），想不起来的留 ○
5. 一周后点 **"🔄 错词循环"** 自动把所有不会的词集中复习

**晚上 20 分钟 - 造句（关键！）：**
1. 打开 `sentence_practice.html`
2. 学 1 个语法点，造 5 句
3. 模板填空 + 录音 + 自检打勾
4. 60 句全过完 = 听说飞升

**碎片时间：** 通勤时听英文播客 / 跟读

## 词汇页新功能（替代 Anki）

✅ **会/不会按钮**：每行末尾的 ○ 按钮
- 点击：○ → ✓（标记为掌握）
- 再点：✓ → ○（取消）
- 掌握的行会变灰并加删除线

✅ **过滤栏**（页面顶部）：
- 📚 **全部** - 默认显示所有词
- ❌ **不会** - 只显示没掌握的（推荐复习用）
- ✓ **已掌握** - 只显示已会的（成就感）
- 🔄 **错词循环** - 自动把所有不会的词抽到顶部，挨个复习，点击标记掌握

✅ **进度自动保存**：所有标记存到 localStorage，刷新不丢

✅ **配合复习模式**：开启 👁️ 模式，英文模糊，看中文回忆
