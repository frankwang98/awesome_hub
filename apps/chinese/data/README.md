# Chinese Practice data

本目录保存语文互动练习的结构化题库。页面只负责展示、出题和记录本地学习状态；内容由数据文件维护，避免把篇目、答案和解释散落在 HTML 中。

## 当前题库

- `poems.json`：古诗词抽背题库。当前为首批已核对篇目，持续按学段扩充。原文将以课程标准篇目为范围，并与开放数据源交叉核验；来源与许可见 `SOURCES.md`。

## 古诗词字段

```text
id              稳定标识
title / author  篇目与作者
level / genre   学段与体裁
text            经核对的完整原文
prompt / answer 正向默写题
reversePrompt / reverseAnswer
                反向默写题
commonMistakes  易错字或词
note            简明理解提示
```

## 建设顺序

1. 小学课程标准 75 首：双向默写、易错字、理解提示。
2. 初中诗词曲：沿用抽背题库，并增加名句、作者和情感线索。
3. 高中诗词曲 40 首：增加意象、结构与鉴赏入口。
4. 初中文言文 20 篇、高中文言文 32 篇：建立独立数据模型，提供实词、句式、翻译、断句和段落理解；不与诗词数据混用。

只有原文、题目和基本解释均已完成并复核的篇目，才计入互动题库完成数。课程标准目录中的其余篇目保持“待建设”状态。
